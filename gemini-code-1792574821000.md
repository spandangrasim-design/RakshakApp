## Sprint 2: Authentication & Master Config

### Issue: Guard & Admin Authentication (JWT)
**Labels:** `backend-api`, `mobile-app`, `frontend-web`
**Description:**
As a user (Guard/Admin), I want to log in using my credentials so that my session is securely authenticated.
**Acceptance Criteria:**
- **Given** I am on the login screen
- **When** I enter a valid Employee ID and Password
- **Then** the system returns a JWT access token and routes me to my dashboard.
- **And** if I enter invalid credentials, I see a "401 Unauthorized" error.
**Tasks:**
- [ ] Build Cloudflare Worker `/auth/login` endpoint.
- [ ] Build React Login Page.
- [ ] Build Flutter Login Screen.

### Issue: Cryptographic QR Code Generator & PDF Export
**Labels:** `frontend-web`, `backend-api`
**Description:**
As a Global Admin, I want to generate signed QR codes for checkpoints and export them as a printable PDF sheet so I can physically mount them on-site.
**Acceptance Criteria:**
- **Given** I have added 5 checkpoints to a site
- **When** I click "Download QR Sheet"
- **Then** the system generates a PDF containing 5 QR codes.
- **And** each QR code payload contains the HMAC-SHA256 signature (`rakshak://cp?s=...`).
**Tasks:**
- [ ] Build QR generation logic (React `qrcode` library).
- [ ] Build PDF layout (React `@react-pdf/renderer`).

## Sprint 3: Guard App Patrol Loop & Anti-Spoofing

### Issue: Mobile Checkpoint Verification (QR + Camera + GPS)
**Labels:** `mobile-app`
**Description:**
As a Security Guard, I want to scan a QR code and take a live photo so that I can prove I visited the checkpoint.
**Acceptance Criteria:**
- **Given** I am in an active patrol round
- **When** I scan a valid checkpoint QR code
- **Then** the app locks me into the native camera to take a Selfie and Location Photo.
- **And** the app prevents me from picking a photo from my phone gallery.
- **And** the app records my live GPS coordinates and monotonic uptime clock.
**Tasks:**
- [ ] Integrate Flutter QR scanner SDK.
- [ ] Lock Flutter Camera API (disable gallery intent).
- [ ] Compress images to <500KB and burn-in text watermark (timestamp, GPS).

### Issue: GPS Geofence Validation (Soft-Flagging)
**Labels:** `backend-api`, `database`
**Description:**
As a System Admin, I want the backend to verify the guard's GPS against the checkpoint's master coordinates to detect spoofing.
**Acceptance Criteria:**
- **Given** a synced scan payload
- **When** the `scan_location` is > 50 meters away from the `master_location`
- **Then** the backend flags the `is_gps_verified` field as `false` (Amber flag).
**Tasks:**
- [ ] Write PostGIS `ST_Distance` query in Supabase/Cloudflare Worker.

## Sprint 4: Offline Storage & Sync Engine

### Issue: Mobile Offline SQLite Queue
**Labels:** `mobile-app`
**Description:**
As a Security Guard in a basement (dead zone), I want my scans to save offline so I don't lose data.
**Acceptance Criteria:**
- **Given** my phone has no internet connection
- **When** I complete a checkpoint scan
- **Then** the scan data and compressed photos are saved to local SQLite.
- **And** I see an "Offline Mode" banner at the top of the app.
**Tasks:**
- [ ] Implement Flutter `sqflite`.
- [ ] Queue failed API requests.

### Issue: Idempotent Auto-Sync Engine
**Labels:** `mobile-app`, `backend-api`
**Description:**
As the System, I want to automatically sync queued offline data when the network returns without creating duplicate records.
**Acceptance Criteria:**
- **Given** I have 3 queued scans
- **When** the phone reconnects to 4G/Wi-Fi
- **Then** the app uploads photos to Cloudflare R2 and POSTs the JSON payload.
- **And** the backend ignores any `client_scan_id` that already exists in the database.
**Tasks:**
- [ ] Build Flutter background network listener.
- [ ] Build Cloudflare Worker `/patrols/sync` endpoint with unique ID constraint checks.

### Issue: Multi-Channel SLA Alerting (Cron Triggers)

**Description:**

**Acceptance Criteria:**

**Tasks:**

- [ ] Integrate Meta WhatsApp Sandbox API.
